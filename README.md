# Embedded Systems Laboratory

Course materials for the STM32 embedded systems laboratory of the [EnICS Labs Institute](https://enicslabs.com/). The labs use the NUCLEO-G491RE development board, with the STM32G491RE microcontroller.

## Course procedures

[procedures.pdf](procedures.pdf) gives the schedule, and the rules for submissions, tests, and grades. Read it before the first session.

## Labs

| Lab | Title | Documents |
|---|---|---|
| 0 | Toolchain Setup and First Flash | [lab00.pdf](lab00-setup/lab00.pdf) |
| 1 | The Morse Code Lock: GPIO and the Memory Map | [Booklet](lab01-gpio/lab01_booklet.pdf), [Tasks](lab01-gpio/lab01_tasks.pdf) |
| 2 | The Noisy Channel: UART, Interrupts, and Modbus RTU | [Booklet](lab02-uart/lab02_booklet.pdf), [Tasks](lab02-uart/lab02_tasks.pdf) |

Each lab has its own folder, with its documents and the files that the lab uses. From Lab 1 on, a lab has two documents: the **booklet** teaches the concepts of the lab, and the **tasks** document gives the pre-laboratory exercises and the tasks. Read each part of the booklet before you do the exercises of that part. You can also download all the files from the [Releases](https://github.com/YuvalHarary/Embedded_Lab_STM32/releases/latest) page.

For Lab 2 Part B, download [lab02_modbus.py](lab02-uart/lab02_modbus.py) and [lab02_partB.ioc](lab02-uart/lab02_partB.ioc). The task document explains how to use them; its tool appendices cover the Serial Monitor and the Python program. Both supplied files are also available together as `lab02_code.zip` on the Releases page.

## Report a problem in a handout

To report an error in a handout, open a new issue and select the form **Problem in a lab handout**. For help with doing a lab, speak to an instructor, as the course procedures tell you.
